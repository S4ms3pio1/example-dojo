
This module walks you through the essential tools of digital forensics, one at a time.
Each challenge introduces a single tool, explains how it works, and gives you a hands-on task to complete with it.
Work through them in order, each one builds on the last.

---

**Note:** Some of the recommended tools are not available in the Dojo, also the challenges require you to investigate image files visually. You may want to copy them to your local machine using `scp`:

```bash
scp -i path-to-key hacker@dojo.pwn.college:/challenge/* ./
```
Alternatively, You can also download files directly from the VS Code editor inside pwn.college, **Workspace → </> Code**

Hold **Ctrl** and click on the files you want to download to select multiple files. Then right-click and select **Download** to download them all at once.

Refer to each tool's official documentation to learn how to use it, or just read the challenge description.
